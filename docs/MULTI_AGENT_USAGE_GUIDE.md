# MemQ usage guide

Start with the [connection and privacy guide](../README.md). Use the supported OAuth flow for your client; do not copy credentials across clients.

## Shared project workflow

Verify identity and scope, recall the relevant checkpoint, do the requested work, verify the outcome, and save selected context when authorized. Teammates using the same authorized workspace can resume from those records. Different projects or organizations do not become shared merely because they use MemQ.

The bundled [skills](../memq-brain/skills) contain the procedures for connection, checkpoints, lessons, team handoffs, and coordination. Discover live tools and schemas; available features and quotas depend on the service and account.

For account or quota issues, use [the dashboard](https://billing.multinex.ai/dashboard) or support@multinex.ai. For evaluation claims and limits, consult [the methodology](https://multinex.ai/benchmarks/memq).
